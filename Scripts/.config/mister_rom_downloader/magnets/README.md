# Drop magnet links and torrent files here
#
# Supported:
#   *.magnet  — magnet URI (one per file)
#   *.txt     — same as magnet (URI on first non-comment line)
#   *.torrent — BitTorrent metadata file (imported as-is, no magnet fetch)
#
# Use Torrent Files → Edit to enable/disable sources.
# Disabled files are skipped by Update Metadata / Search catalog rebuild.
#
# Magnet/torrent files are local-only and are not included in the git repository.
